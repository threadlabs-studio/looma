# Link Card

The actions bar for a link in the editor: its destination, Open link, Edit link, and Remove link.
The card shows `label` and `detail` for a resolved destination, or the address in `href` when
there is none. Open link opens `open-href` in a new tab and appears only when it is set; the
editor sets it for an http, https, mailto, tel, or relative address. Edit link and Remove link
report `edit` and `remove` for the editor to act on, and pressing them keeps the editor's
selection. Each command has a tooltip. The compact bar uses icon actions and a single-line destination; long names and addresses truncate, with the full address retained in the destination’s title and accessible label.
