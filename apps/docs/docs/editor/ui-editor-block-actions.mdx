# Block Actions

The editor's block menu: insert a paragraph below, duplicate, or delete the block that holds the caret.
The menu opens from the button named by `for` and reports `open` when it does, so the editor can
note the block. Each choice reports `action` with `insert-below`, `duplicate`, or `delete`, and
the editor changes the document.
