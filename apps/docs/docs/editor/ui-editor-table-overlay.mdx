# Table Overlay

Anticipatory table controls for exact-boundary insertion and table actions. The row and column
handles select that axis and request a menu anchored to the handle; the cell handle requests a
cell menu. The editor integration positions the menu and supplies the actions valid for the
selection. The overlay reports logical row and column indices and viewport anchor coordinates,
without owning editor commands.
