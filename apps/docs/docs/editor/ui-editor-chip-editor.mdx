# Chip Editor

The editor's chip editor: a field for the chip's text and swatches for its colour.
It reports `label` as the text changes and `color` when a swatch is chosen, and the editor updates
the chip. Enter or Escape in the field reports `done`, so the editor can close it and return to the
chip. A swatch chosen with the pointer returns focus to the field; the arrow keys move between
swatches.
