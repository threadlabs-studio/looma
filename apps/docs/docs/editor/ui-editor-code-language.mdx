# Code Language

The code block's language picker: a compact combobox of the languages the editor can highlight, with Auto first.
Typing filters the list by label. Choosing a language reports `language` with its value, or
`auto`, and the editor sets the code block's language. Its label, Code language, is for screen
readers only.
