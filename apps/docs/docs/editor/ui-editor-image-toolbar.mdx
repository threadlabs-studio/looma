# Image Toolbar

Contextual actions for a selected image: four placement commands, a description form, and delete.
The toolbar reports each choice as a request, `placement`, `describe`, or `delete`, and leaves the
document change to the editor. `placement` marks the current choice as pressed. Image description
opens a form that starts from `alt`; Save requests that text for the image the form opened for, and
a change of `target` cancels an open draft rather than applying it to another image. Each command
has a tooltip, and the toolbar has one Tab stop with arrow keys between its commands.
