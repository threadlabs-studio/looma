# Footnote Editor

The floating footnote editor frame. Compose a rich-text field in its default slot, or use its simple note field. The document numbers references automatically; Changes apply as you type; Escape or clicking away closes the editor.

Adding a footnote opens the floating rich-text editor. An existing reference opens a one-line action bar: Go to note is an icon button with a tooltip, and Edit note has a pencil icon. Formatting and multiple paragraphs remain editable, while Markdown export writes definitions at the end of the document.
