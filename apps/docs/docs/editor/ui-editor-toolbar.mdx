# Toolbar

Semantic, slot-based toolbar frame for app-owned editor command controls. It keeps its controls on one row that scrolls sideways when space runs out, fading each edge that hides controls into the toolbar's colour; `--ui-editor-toolbar-fade-size` sets the fade's width.
