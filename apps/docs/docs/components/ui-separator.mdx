# Separator

Semantic separator primitive with horizontal and vertical orientations.

## Component Reference

## Attributes

| Name | Type | Default | Notes |
| --- | --- | --- | --- |
| `orientation` | `horizontal \| vertical` | `horizontal` | Reflected in `aria-orientation` when role is `separator`. |
| `role` | `separator \| string` | `separator` | Non-separator role suppresses ARIA orientation reflection. |

| Name | Type |
