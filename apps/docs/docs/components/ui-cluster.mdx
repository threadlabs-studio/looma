# Cluster

Cluster layout primitive for wrapping item groups with shared alignment controls.

## Component Reference

<ComponentExamplesApiTabs component="ui-cluster" />

## Attributes

| Name | Type | Default |
| --- | --- | --- |
| `gap` | `xs \| s \| m \| string` | `s` |
| `align` | `start \| center \| end \| stretch` | `center` |
| `justify` | `start \| center \| end \| between` | `start` |

## Properties

| Name | Type |
| --- | --- |
| `gap` | `string` |
| `align` | `string` |
| `justify` | `string` |

## Events

No custom events.

## Slots

Default slot only.

## SSR Markup

```html
<ui-cluster gap="s" justify="between">
  <span>Status: Active</span>
  <ui-inline gap="s">
    <button type="button">Save</button>
    <button type="button">Cancel</button>
  </ui-inline>
</ui-cluster>
```
