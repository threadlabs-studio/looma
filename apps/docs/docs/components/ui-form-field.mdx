# Form Field

Form-field composition primitive that links label/control/description semantics.

## Component Reference

<ComponentExamplesApiTabs component="ui-form-field" />

## Attributes

| Name | Type | Default |
| --- | --- | --- |
| `invalid` | `boolean` | `false` |
| `required` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |

## Properties

| Name | Type |
| --- | --- |
| `invalid` | `boolean` |
| `required` | `boolean` |
| `disabled` | `boolean` |

## Events

No custom events.

## Slots

Default slot; recommended children:

- `label`
- control (`ui-input`, `input`, `textarea`, `select`, `button`)
- optional help/error text with `data-slot="help"` and `data-slot="error"`

## SSR Markup

```html
<ui-form-field required>
  <label for="email">Email</label>
  <ui-input>
    <input id="email" name="email" type="email" />
  </ui-input>
  <small data-slot="help">We only use this for account notifications.</small>
</ui-form-field>
```
