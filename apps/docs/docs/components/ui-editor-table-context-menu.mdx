# Editor Table Context Menu

Cell and table action menu whose available commands are controlled by app-provided capabilities.

## Component Reference

<ComponentExamplesApiTabs component="ui-editor-table-context-menu" />

## Runtime Contract

Set `open`, `cell-background`, and the `can-*` attributes from the active Tiptap selection. Selecting an available command emits `looma-editor-table-action` with `{ action }`. The app owns command execution, closing, focus restoration, and content persistence.

The menu groups background, structural, cell, and destructive actions and hides unavailable commands. It is client-generated enhancement UI with no no-JS fallback. Essential table actions must also be keyboard-discoverable outside a pointer-only context gesture, and touch layouts need a visible entry point.

## Candidate Limitation

E-TBL-003 tracks the remaining discoverability and interaction-quality gap. Data loss or corruption is never an accepted limitation.
