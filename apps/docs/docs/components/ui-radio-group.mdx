# Radio Group

Grouped selection primitive that coordinates `ui-radio` descendants, keyboard navigation, and normalized selection events.

## Component Reference

<ComponentExamplesApiTabs component="ui-radio-group" />

## Attributes

| Name | Type | Default |
| --- | --- | --- |
| `value` | `string` | `""` |
| `name` | `string` | `""` |
| `disabled` | `boolean` | `false` |
| `required` | `boolean` | `false` |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |

## Properties

| Name | Type |
| --- | --- |
| `value` | `string` |
| `name` | `string` |
| `disabled` | `boolean` |
| `required` | `boolean` |
| `orientation` | `"horizontal" \| "vertical"` |

## Events

| Name | Detail |
| --- | --- |
| `select` | `{ value, previousValue, trigger }` |
| `change` | `{ checked, value, trigger }` |

## Slots

Default slot; expects `ui-radio` children.

## SSR Markup

```html
<ui-radio-group value="starter" name="plan">
  <ui-radio value="starter">Starter</ui-radio>
  <ui-radio value="pro">Pro</ui-radio>
</ui-radio-group>
```
