# ui-tabs

Tablist primitive that synchronizes tab focus, selection, and panel visibility.

## Attributes

| Name | Type | Default |
| --- | --- | --- |
| `value` | `string` | first tab id |
| `default-value` | `string` | empty |
| `orientation` | `horizontal \| vertical` | `horizontal` |

## Properties

| Name | Type |
| --- | --- |
| `value` | `string` |
| `defaultValue` | `string` |
| `orientation` | `"horizontal" \| "vertical"` |

## Events

| Name | Detail |
| --- | --- |
| `select` | `{ value, previousValue?, trigger }` |

## Slots

Default slot with authored tablist/tabs/panels.

## SSR Markup

```html
<ui-tabs>
  <div role="tablist" aria-label="Sections">
    <button role="tab" id="tab-overview" aria-controls="panel-overview">Overview</button>
    <button role="tab" id="tab-details" aria-controls="panel-details">Details</button>
  </div>
  <section role="tabpanel" id="panel-overview" aria-labelledby="tab-overview">Overview content</section>
  <section role="tabpanel" id="panel-details" aria-labelledby="tab-details" hidden>Details content</section>
</ui-tabs>
```
