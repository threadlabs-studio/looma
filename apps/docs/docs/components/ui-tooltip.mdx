# Tooltip

Contextual overlay primitive that links descriptive content to a trigger element.

## Component Reference

<ComponentExamplesApiTabs component="ui-tooltip" />

## Attributes

| Name | Type | Default |
| --- | --- | --- |
| `for` | `string` | empty |
| `open` | `boolean` | `false` |
| `default-open` | `boolean` | `false` |

## Properties

| Name | Type |
| --- | --- |
| `for` | `string` |
| `open` | `boolean` |
| `defaultOpen` | `boolean` |

## Events

| Name | Detail |
| --- | --- |
| `open` | `{ open: true, reason, trigger }` |
| `close` | `{ open: false, reason, trigger }` |

## Slots

Default slot for tooltip content.

## SSR Markup

```html
<button id="help-trigger" type="button">Help</button>
<ui-tooltip for="help-trigger">Helpful guidance.</ui-tooltip>
```
