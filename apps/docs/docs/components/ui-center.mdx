# Center

Container primitive for readable measure and horizontal gutters.

## Component Reference

<ComponentExamplesApiTabs component="ui-center" />

## Attributes

| Name | Type | Default |
| --- | --- | --- |
| `measure` | `narrow \| wide \| string` | `65ch` |
| `gutters` | `s \| m \| l \| string` | `m` |

Center fills the available width until it reaches its measure. Its gutters are
part of that measured box, so the primitive stays viewport-safe when nested in
narrow panels or application shells.

## Properties

| Name | Type |
| --- | --- |
| `measure` | `string` |
| `gutters` | `string` |

## Events

No custom events.

## Slots

Default slot only.

## SSR Markup

```html
<ui-center measure="wide" gutters="m">
  <h1>Page Title</h1>
  <p>Readable line length with consistent side gutters.</p>
</ui-center>
```
