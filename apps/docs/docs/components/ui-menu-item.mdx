# Menu Item

Focusable menu item primitive intended for use inside `ui-menu`.

## Component Reference

<ComponentExamplesApiTabs component="ui-menu-item" />

## Attributes

| Name | Type | Default |
| --- | --- | --- |
| `value` | `string` | text content |
| `disabled` | `boolean` | `false` |

## Properties

| Name | Type |
| --- | --- |
| `value` | `string` |
| `disabled` | `boolean` |

## Events

No direct custom events (selection is emitted by parent `ui-menu`).

## Slots

Default slot for menu item label/content.

## SSR Markup

```html
<ui-menu role="menu">
  <ui-menu-item value="edit">Edit</ui-menu-item>
  <ui-menu-item value="archive" disabled>Archive</ui-menu-item>
</ui-menu>
```

## Framework Snippets

```vue
<script setup lang="ts">
import { Menu, MenuItem } from "@threadlabs/looma/vue";
</script>

<template>
  <Menu role="menu">
    <MenuItem value="edit">Edit</MenuItem>
    <MenuItem value="archive" disabled>Archive</MenuItem>
  </Menu>
</template>
```
