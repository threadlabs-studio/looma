# ui-button

Essential button primitive that enhances semantic button markup and styling hooks.

## Component Reference

<ComponentExamplesApiTabs component="ui-button" />

## Attributes

| Name | Type | Default |
| --- | --- | --- |
| `variant` | `string` | empty |
| `size` | `string` | empty |
| `disabled` | `boolean` | `false` |

## Properties

| Name | Type |
| --- | --- |
| `variant` | `string` |
| `size` | `string` |
| `disabled` | `boolean` |

## Events

Uses native click/keyboard activation semantics.

## Slots

Default slot. Typically contains a native `<button>`.

## SSR Markup

```html
<ui-button variant="solid" size="sm">
  <button type="button" aria-label="Save page">
    <span aria-hidden="true">✦</span>
    Save page
  </button>
</ui-button>
```
