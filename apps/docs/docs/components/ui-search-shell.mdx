# Search Shell

Overlay shell for search and command-palette experiences. It owns the backdrop/panel layout and responsive fullscreen behavior while apps keep query state, result rendering, and routing.

## Component Reference

<ComponentExamplesApiTabs component="ui-search-shell" />

## Attributes

None.

## Properties

None.

## Events

None.

## Slots

- `backdrop`: backdrop layer behind the panel.
- `search`: search input/header row.
- `status`: optional loading/status row.
- `body`: results, recent searches, or empty states.
- `footer`: optional footer row.

## SSR Markup

```html
<ui-search-shell>
  <button slot="backdrop" type="button" aria-label="Close search"></button>
  <div slot="search">…search input row…</div>
  <div slot="body">…results…</div>
  <div slot="footer">Press ⌘K to toggle</div>
</ui-search-shell>
```
