# Editor Toolbar

Semantic, slot-based toolbar frame for app-owned editor command controls.

## Component Reference

<ComponentExamplesApiTabs component="ui-editor-toolbar" />

## SSR And No-JS Contract

```html
<ui-editor-toolbar aria-label="Text formatting">
  <button type="button" aria-pressed="false">Bold</button>
  <button type="button" aria-pressed="false">Italic</button>
</ui-editor-toolbar>
```

The slotted buttons are the semantic fallback. Upgrade supplies the toolbar role and default label when the author omits them. Keep controls keyboard-operable and at least 44px on touch layouts.

## Vue

`LoomaEditor` renders this toolbar with Looma `IconButton` controls and owns the
Tiptap commands. Advanced consumers can still use `EditorToolbar` from
`@threadlabs/looma/vue/editor` and provide custom controls and command wiring through its default slot.
