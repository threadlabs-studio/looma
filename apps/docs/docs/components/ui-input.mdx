# ui-input

Essential text-input primitive that mirrors value/state to native input controls.

## Attributes

| Name | Type | Default |
| --- | --- | --- |
| `value` | `string` | empty |
| `default-value` | `string` | empty |
| `disabled` | `boolean` | `false` |
| `readonly` | `boolean` | `false` |
| `invalid` | `boolean` | `false` |

## Properties

| Name | Type |
| --- | --- |
| `value` | `string` |
| `defaultValue` | `string` |
| `disabled` | `boolean` |
| `readOnly` | `boolean` |
| `invalid` | `boolean` |

## Events

Uses native `input` and `change` behavior via internal control synchronization.

## Slots

Default slot (typically one native `<input>` child).

## SSR Markup

```html
<ui-input value="hello">
  <input type="text" name="title" />
</ui-input>
```
