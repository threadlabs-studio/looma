# Select

Native-select wrapper primitive that mirrors value and state to a slotted `<select>` while applying shared Looma styling.

## Component Reference

<ComponentExamplesApiTabs component="ui-select" />

## Attributes

| Name | Type | Default |
| --- | --- | --- |
| `value` | `string` | empty |
| `default-value` | `string` | empty |
| `disabled` | `boolean` | `false` |
| `required` | `boolean` | `false` |
| `invalid` | `boolean` | `false` |

## Properties

| Name | Type |
| --- | --- |
| `value` | `string` |
| `defaultValue` | `string` |
| `disabled` | `boolean` |
| `required` | `boolean` |
| `invalid` | `boolean` |

## Events

Uses native `input` and `change` behavior via internal control synchronization.

## Slots

Default slot (typically one native `<select>` child).

## SSR Markup

```html
<ui-select value="editor">
  <select name="role">
    <option value="viewer">Viewer</option>
    <option value="editor">Editor</option>
    <option value="admin">Admin</option>
  </select>
</ui-select>
```
