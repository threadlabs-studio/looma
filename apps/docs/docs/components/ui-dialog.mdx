# Dialog

Overlay primitive that coordinates native `dialog` behavior with shared overlay stack rules.

## Component Reference

<ComponentExamplesApiTabs component="ui-dialog" />

## Attributes

| Name | Type | Default | Notes |
| --- | --- | --- | --- |
| `open` | `boolean` | `false` | Controls open state. |
| `default-open` | `boolean` | `false` | Initial uncontrolled open state. |
| `modal` | `boolean-like` | `true` | `modal="false"` disables modal mode. |

## Properties

| Name | Type |
| --- | --- |
| `open` | `boolean` |
| `defaultOpen` | `boolean` |
| `modal` | `boolean` |

## Events

| Name | Detail |
| --- | --- |
| `open` | `{ open: true, reason, trigger }` |
| `close` | `{ open: false, reason, trigger }` |

## Slots

Default slot (typically contains one native `<dialog>` child).

## SSR Markup

```html
<ui-dialog open>
  <dialog>
    <h2>Settings</h2>
    <p>Dialog body copy.</p>
    <button value="close">Close</button>
  </dialog>
</ui-dialog>
```
