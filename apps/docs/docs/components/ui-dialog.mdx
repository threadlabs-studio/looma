# Dialog

Overlay primitive that coordinates native `dialog` behavior with shared overlay stack rules.

## Component Reference

<ComponentExamplesApiTabs component="ui-dialog" />

## Attributes

| Name | Type | Default | Notes |
| --- | --- | --- | --- |
| `open` | `boolean` | `false` | Controls open state. |
| `default-open` | `boolean` | `false` | Initial uncontrolled open state. |
| `modal` | `boolean-like` | `true` | `modal="false"` disables modal mode. |
| `dismissible` | `boolean-like` | `true` | Enables Escape and backdrop dismissal. |
| `label` | `string` | — | Accessible name for the native dialog surface. |

## Properties

| Name | Type |

## Events

| Name | Detail |
| --- | --- |
| `open` | `{ open: true, reason, trigger }` |
| `close` | `{ open: false, reason, trigger }` |

## Slots

Default slot for dialog content. `ui-dialog` owns the native `<dialog>`; do not
nest another one. Provide `label` for a stable, localized accessible name. If it
is omitted, the first slotted heading (or `[data-ui-dialog-title]`) is observed
reactively and used, with `"Dialog"` as the final fallback.

## SSR Markup

```html
<ui-dialog open label="Settings">
  <h2>Settings</h2>
  <p>Dialog body copy.</p>
  <button value="close">Close</button>
</ui-dialog>
```

## Framework Snippets

```vue
<script setup lang="ts">
import { Dialog } from "@threadlabs/looma/vue";

function onClose(detail: unknown) {
  console.log(detail);
}
</script>

<template>
  <Dialog label="Settings" @close="onClose">
    <h2>Settings</h2>
    <p>Dialog body copy.</p>
    <button value="close">Close</button>
  </Dialog>
</template>
```
