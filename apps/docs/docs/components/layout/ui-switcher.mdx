# Switcher

Intrinsic layout that stacks when its container becomes too narrow, with equal columns or a narrower rail beside the detail.
Set `limit` to the most children allowed in a horizontal row. If the child count exceeds the limit,
all children stack even when the container is wide. Omit it when only `threshold` should decide.

For a rail or inspector, use the `start` and `end` slots with `balance="narrow-start"`
or `balance="narrow-end"`. On a narrow container, the start pane stacks above the end pane.
