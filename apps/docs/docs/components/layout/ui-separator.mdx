# Separator

Semantic separator primitive with horizontal and vertical orientations.

Separator renders a native `<hr>`, which has no content slot. Give a meaningful separator a native
`aria-label`; use an adjacent heading when the text itself should be visible. Keep purely visual
rules in CSS when they should have no separator semantics.


<ComponentExamplesApiTabs component="ui-separator" />

Use `emphasis="strong"` for clearer separation within a compact composition. The default
keeps the ordinary decorative divider color, and both orientations use the same emphasis.
