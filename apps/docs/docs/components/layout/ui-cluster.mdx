# Cluster

Cluster layout primitive for row-style content with wrapping support. Set `wrap="nowrap"` to keep a small group, such as a meter and its value, on one row. Set `maxRows` with an `overflow` slot to show complete rows and reveal the remaining items through your action. The optional `trailing` slot stays visible within the row limit. The `overflow-change` event reports the hidden count. Omit maxRows for ordinary unbounded wrapping.


Set `align="baseline"` to align the first text baselines when neighbouring columns use different line heights or wrap onto several lines.
