# Textarea

Multiline text-input primitive that mirrors value, rows, disabled, readonly, and invalid state to a native `<textarea>`.

## Component Reference

<ComponentExamplesApiTabs component="ui-textarea" />

## Attributes

| Name | Type | Default |
| --- | --- | --- |
| `value` | `string` | empty |
| `default-value` | `string` | empty |
| `disabled` | `boolean` | `false` |
| `readonly` | `boolean` | `false` |
| `invalid` | `boolean` | `false` |
| `rows` | `number` | `4` |

## Properties

| Name | Type |
| --- | --- |
| `value` | `string` |
| `defaultValue` | `string` |
| `disabled` | `boolean` |
| `readOnly` | `boolean` |
| `invalid` | `boolean` |
| `rows` | `number` |

## Events

Uses native `input` and `change` behavior via internal control synchronization.

## Slots

Default slot (typically one native `<textarea>` child).

## SSR Markup

```html
<ui-textarea value="Notes" rows="5">
  <textarea name="notes"></textarea>
</ui-textarea>
```
