# Affordance Scope

A lightweight interaction scope that lets nearby controls anticipate pointer movement without adding listeners or hit regions to every control.

**Import:** `import "@threadlabs/looma"` — or use `AffordanceScope` from `@threadlabs/looma/vue`.

</div>

## Interaction model

The scope listens once, schedules at most one calculation per animation frame, and caches descendant affordance geometry between layout changes. Every affordance within the configured radius receives the same presentation-only near state, so near regions can overlap naturally. Only the visible controls participate in hit testing.

Pointer proximity is skipped for touch input. Keyboard focus and direct hover continue to reveal the real control.

## Framework snippet

```vue
<script setup lang="ts">
import { AffordanceScope, IconButton } from "@threadlabs/looma/vue";
</script>

<template>
  <AffordanceScope :near-radius="32">
    <IconButton anticipatory label="Add item">+</IconButton>
  </AffordanceScope>
</template>
```
