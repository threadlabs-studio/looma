# Switch

Binary control primitive that reflects switch semantics for checked state.

## Component Reference

<ComponentExamplesApiTabs component="ui-switch" />

## Attributes

| Name | Type | Default |
| --- | --- | --- |
| `checked` | `boolean` | `false` |
| `default-checked` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
| `required` | `boolean` | `false` |
| `value` | `string` | `on` |

## Properties

| Name | Type |
| --- | --- |
| `checked` | `boolean` |
| `defaultChecked` | `boolean` |
| `disabled` | `boolean` |

## Events

| Name | Detail |
| --- | --- |
| `change` | `{ checked, value, trigger }` |

## Slots

Default slot. Typically wraps a native `<input type="checkbox">`.

## SSR Markup

```html
<ui-switch value="notifications">
  <input type="checkbox" name="notifications" />
  Enable notifications
</ui-switch>
```
