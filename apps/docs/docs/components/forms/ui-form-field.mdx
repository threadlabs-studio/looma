# Form Field

Form-field composition primitive that links label/control/description semantics.

Put help in the `help` slot and a validation message in the `error` slot. The message stays hidden
and out of the control's description until `invalid` is true. Pair `required` with a visible cue
in the authored label so people know a value is needed before validation runs.

Put a small action about the label, such as a help button that opens a toggletip, in the
`label-action` slot, not inside the label. It sits after the label text in a box one line tall,
centred on the first line, so a button taller than the text never makes that field's label row
taller than its neighbours' in a grid row. Name the button for what it explains ("Help for Price").

## Connect labels to controls

Give the control an `id` and the label a matching `for`, or put the control inside the `<label>`.
Either way, clicking the label focuses the right control immediately. The field can connect a
label with no `for` once it loads, but the authored connection also works before that. Keep each
`id` unique on the page; a copied field that keeps its `id` leaves its label pointing at the
first control.

In development, the field warns in the console when it links a label for you, when its control's
`id` is not unique, or when its label's `for` points at another element. Production builds
(`process.env.NODE_ENV` set to `"production"`) do not warn.

## Styling hooks

Set these on the field through a class of your own. They do not inherit, so a field inside the one
you set them on keeps its defaults.

| Hook | Sets |
| --- | --- |
| `--ui-form-field-label-text`, `--ui-form-field-label-font-size` | the label's colour (`--ui-text-secondary`) and size (`--ui-font-size-sm`) |
| `--ui-form-field-help-text`, `--ui-form-field-help-font-size` | the help text's colour (`--ui-text-muted`) and size (`--ui-font-size-sm`) |
| `--ui-form-field-help-min-block-size` | a minimum height for the help, so fields in a row line up |
| `--ui-form-field-min-inline-size` | the narrowest the field gets (`0`), such as `16rem` in a wrapping row |
| `--ui-form-field-danger` | the error message's colour, over the inherited `--ui-field-danger` |
