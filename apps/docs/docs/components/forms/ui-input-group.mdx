# Input Group

An Input with fixed text before or after it: the domain a site's address ends in, the slashes
around a path. The group draws one field around the input and its affixes, with one border and one
focus ring, and an invalid input marks the whole group. The input inside is still a `ui-input`, so it
submits with its form and takes its own `id`, `name`, and `v-model`. Name it with a label that says
what the whole value is ("Site address"); the affixes are plain text beside it.
