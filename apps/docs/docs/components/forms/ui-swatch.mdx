# Swatch

A round colour dot that is a native radio, named by its tone, for choosing a colour inside a radio group.
Its six tones (neutral, blue, green, yellow, red and purple) use the same tokens as editor chips,
and its value is its tone. Place swatches in a `ui-radio-group`: the group names them, checks the
one matching its `value`, moves between them with the arrow keys, and reports the choice. The
checked swatch and the focused one show a ring at the focus width.
