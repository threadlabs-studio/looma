# Button

Essential button primitive that enhances semantic button markup and styling hooks. Ghost choices use the shared selection surface and text tokens for their selected visual state while the composing control owns ARIA selection semantics. Unselected disabled ghost actions stay transparent; an unavailable selected choice keeps a muted selection wash.

Use `interaction-tone="accent"` to keep a neutral button quiet at rest and accent it on hover or press.
`interaction-variant` can choose `outline`, `solid`, or `ghost` paint without changing layout.
Both settings default to `inherit`, following the resting tone and variant, including presets. Pressed feedback remains distinct from hover.

Supply `href` to render a native link automatically: `<ui-button href="/guide">Read the guide</ui-button>`
or `<Button href="/guide">Read the guide</Button>` in Vue. Omit `href` for a native button.
`target` and `rel` apply to links; `type` applies to buttons.

Set `loading` while an action is running. The button keeps its label and keyboard focus, shows a
spinner, exposes `aria-disabled` and `aria-busy`, and blocks clicks and form submission. Clear the
prop when the action finishes. This also works with `href`: the loading link keeps its focus
position but cannot navigate.

Put a non-interactive count in the `badge` slot of a boxed Button sized `sm` or larger. The slot keeps a 24px Badge inside
the standard control height, so it aligns with an ordinary Button and a matching IconButton. Use
`shape="circle" size="sm"` for compact counts through `99+`, and `variant="inverse"` with the filled
button's tone. Name the full count on the button and hide a redundant count from assistive technology.
Large content can still grow the button. Existing default-slot content keeps its spacing.

```vue
<Button size="sm" variant="solid" aria-label="Submit 120 items">
  Submit
  <template #badge><Badge shape="circle" size="sm" variant="inverse" tone="accent" aria-hidden="true">99+</Badge></template>
</Button>
```

## Value-picker field variant

Use `variant="field"` to open a custom value picker. It shares Select's subtle
outline, neutral text, surface and slight resting lift, regardless of action
tone. Use `aria-expanded` to expose an open picker; that state presses the
trigger inward. Keyboard focus retains its halo and disabled controls lose
their lift. Use Select for a native list of plain options.

Match the adjacent Input's size: `sm` with `sm`, `md` with `md`. Single-line
fields and their triggers share the same outer height. Checkboxes, multiline
fields and content that intentionally expands have their own geometry.

## CardButton variant

Use `variant="card"` for one whole-card action. It reuses Button's `tone`, loading, disabled,
link and form behavior. Its uniform border and equal inline padding use the standard Button
palette and spacing; there is no emphasized side edge.
Neutral cards use the standard decorative border. Neutral outline actions share fields’
control border; accent and other intent outlines use their tone-colored edge. Buttons
default to neutral; choose `tone="accent"` or `preset="primary"` for emphasis.

Put arbitrary decorative content in the `icon` slot. Icon and main content align at the top;
the grid row centers within spare height so single-line labels look vertically centered, and
the content receives the remaining grid width. The `action` slot centers vertically and defaults
to the shared right caret. Both column gaps use the standard spacing token. Without an icon,
its column and extra gap disappear. A custom action stays decorative within the one control;
do not put another button or link inside it.

In Vue, use `<Button variant="card" tone="accent">` with `#icon` and optional `#action` slots.
In HTML, use `<ui-button variant="card">` and children with `slot="icon"` or `slot="action"`.

## Theming

Set `--ui-accent` or `--ui-danger` on the theme root to change the action palette. Set the inherited
`--ui-action-radius` on a section to change Button and Icon Button corners together. Set
`--ui-button-radius` on one Button for an exception. The [theming guide](/tokens) explains the global,
group, and component levels.

Boxed Button and IconButton actions have a flat face, one fine top/leading highlight and bottom/trailing
lowlight, and a single ambient shadow. Their default does not stack a face gradient or another inset bevel.
Joined actions show the trailing lowlight immediately before the next action's leading highlight.
Set inherited `--ui-action-edge` to replace those inset edges, or `--ui-action-shadow` to replace the
whole resting shadow for both components. Component shadow hooks still take precedence. Ghost and
link actions stay flat; focus, pressed and disabled treatments retain their usual meaning.

A label wraps as its container's text does. To keep one on a single line, such as in a narrow table
cell, set `--ui-button-white-space: nowrap` on that button through a class of your own. It takes
any `white-space` value; unset, the button inherits its container's.


## Touch targets

Touch input keeps a boxed button's visible size. Icon buttons and inline link actions can provide an
invisible hit area through `--ui-control-min-block-size`, whose 44px default is an adjustable comfort
preference. Choose target sizes and surrounding spacing for the context so neighbouring controls do
not take each other's presses.
