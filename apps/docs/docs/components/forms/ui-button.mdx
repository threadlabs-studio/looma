# Button

Essential button primitive that enhances semantic button markup and styling hooks.


## Touch targets

Under touch input (a coarse pointer, or touch used on this page), every button takes presses within
the control minimum, 44px: a boxed button grows to it, and any smaller button, a link-style one
included, gets an invisible hit area of that size centred on it, as Icon Button does.
