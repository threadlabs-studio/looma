# Textarea

Multiline input that lowers directly to a native `<textarea>` while applying Looma's shared control theme.

Set `autosize` to let the field grow and shrink with its text. `rows` remains its minimum height.
This uses CSS field sizing in browsers that support it; elsewhere the native `rows` height remains.
