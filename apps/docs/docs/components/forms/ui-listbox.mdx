# Listbox

Keep choices visible in a styled list. A selected choice stays visible; in `multiple` mode, each row uses the same checkmark treatment as Combobox suggestions. Click to choose, use arrow keys to move, and press Space to toggle a multiple choice.

<ComponentExamplesApiTabs component="ui-listbox" />

Author `<option>` and `<optgroup>` children for the labels, values, disabled state, and initial `selected` state. Give the list an accessible name with `aria-label` or `aria-labelledby`. `value` and `values` set its selection from application state; `change` reports the new values. A named list contributes one form entry per selection and returns to its initial selection on form reset.

The `required` prop prevents form submission with no selection. A disabled list cannot change or submit a value. Use [Select](/components/ui-select) when one choice belongs in a compact dropdown, or [Combobox](/components/ui-combobox) when users need to search choices.
