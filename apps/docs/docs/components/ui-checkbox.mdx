# Checkbox

Form control primitive for boolean and mixed selection state.

## Component Reference

<ComponentExamplesApiTabs component="ui-checkbox" />

## Attributes

| Name | Type | Default |
| --- | --- | --- |
| `checked` | `boolean` | `false` |
| `default-checked` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
| `required` | `boolean` | `false` |
| `value` | `string` | `on` |
| `indeterminate` | `boolean` | `false` |

| Name | Detail |
| --- | --- |

## Slots

Default slot. Typically wraps a native `<input type="checkbox">`.

## SSR Markup

```html
<ui-checkbox value="newsletter">
  <label>
    <input type="checkbox" name="newsletter" />
    <span>Subscribe to updates</span>
  </label>
</ui-checkbox>
```

Wrap the input and label text in a `<label>` so clicking the text toggles the checkbox.
