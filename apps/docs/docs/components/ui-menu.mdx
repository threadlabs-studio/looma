# Menu

Menu container primitive that manages focus and selection across `ui-menu-item` children.

## Component Reference

<ComponentExamplesApiTabs component="ui-menu" />

## Attributes

| Name | Type | Default |
| --- | --- | --- |
| `open` | `boolean` | `false` |
| `default-open` | `boolean` | `false` |

## Properties

| Name | Type |
| --- | --- |
| `open` | `boolean` |
| `defaultOpen` | `boolean` |

## Events

| Name | Detail |
| --- | --- |
| `open` | `{ open: true, reason, trigger }` |
| `close` | `{ open: false, reason, trigger }` |
| `select` | `{ value, trigger }` |

## Slots

Default slot; expects `ui-menu-item` descendants.

## SSR Markup

```html
<ui-menu role="menu" aria-label="Actions">
  <ui-menu-item value="edit">Edit</ui-menu-item>
  <ui-menu-item value="archive">Archive</ui-menu-item>
</ui-menu>
```

## Framework Snippets

```vue
<script setup lang="ts">
import { Menu, MenuItem } from "@threadlabs/looma/vue";

function onSelect(detail: unknown) {
  console.log(detail);
}
</script>

<template>
  <Menu @select="onSelect">
    <MenuItem value="edit">Edit</MenuItem>
    <MenuItem value="archive">Archive</MenuItem>
  </Menu>
</template>
```
