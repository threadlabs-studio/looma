# Editor Slash Menu

Responsive suggestion surface for app-provided slash commands.

## Component Reference

<ComponentExamplesApiTabs component="ui-editor-slash-menu" />

## Runtime Contract

Apps set `open`, `query`, `items`, `selectedIndex`, and `anchorRect` as properties. The element emits `looma-editor-slash-menu-highlight` and `looma-editor-slash-menu-select` with `{ index }`; the app maps the index to its command and owns the editor mutation.

On desktop the menu positions near the supplied anchor. On narrow viewports it becomes a bottom surface. Pointer movement changes highlight; click selects. The editor integration owns arrow-key and Enter routing.

This is a client enhancement with no generated no-JS menu. The document content and another insertion path must remain usable when it is absent. The module itself is safe to import during SSR.

## Vue

Use `EditorSlashMenu` from `@threadlabs/looma/vue/editor` and pass the vanilla Tiptap editor state through the documented properties and events.
