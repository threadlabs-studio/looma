# Avatar Group

Container that displays overlapping avatars with an optional "+N" overflow pill when the count exceeds the visible maximum.

## Component Reference

<ComponentExamplesApiTabs component="ui-avatar-group" />

## Attributes

| Name | Type | Default |
| --- | --- | --- |
| `max` | `number` | `5` |
| `label` | `string` | `"People"` |

## Properties

| Name | Type |
| --- | --- |
| `max` | `number` |
| `label` | `string` |

## Events

None.

## Slots

Default slot: direct children are shown as overlapping avatars; only the first `max` are visible, with a "+N" pill for the rest.

Overflow visibility is shadow-owned presentation. Reactive frameworks retain
ownership of the slotted nodes and the component does not add or remove
`hidden`/`aria-hidden` attributes. The host exposes a labelled `group`, avoiding
invalid list semantics for arbitrary slotted avatar content.

## SSR Markup

```html
<ui-avatar-group max="5" label="People">

  </ui-avatar>
  <ui-avatar name="Sam" src="/b.png" alt="Sam">

  </ui-avatar>
</ui-avatar-group>
```
