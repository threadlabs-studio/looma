# ui-grid

Responsive auto-fit grid primitive.

## Attributes

| Name | Type | Default | Notes |
| --- | --- | --- | --- |
| `gap` | `xs \| s \| m \| l \| string` | `m` | Grid gutter size. |
| `min` | `sm \| md \| lg \| string` | `md` | Minimum column width token. |

## Properties

| Name | Type |
| --- | --- |
| `gap` | `string` |
| `min` | `string` |

## Events

No custom events.

## Slots

Default slot only.

## SSR Markup

```html
<ui-grid gap="m" min="md">
  <article>Card A</article>
  <article>Card B</article>
  <article>Card C</article>
</ui-grid>
```
