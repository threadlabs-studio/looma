# Popover

Non-modal overlay primitive with shared open/close lifecycle. Click activation toggles from its anchor by default; trigger=manual retains anchoring, expanded state, Escape and light dismissal while the caller controls open, including when switching between anchor controls.

Use `bare` when the content supplies its own surface, such as a floating toolbar. It removes the
popover's padding, border, background, shadow, and overflow clipping so the content's shadow stays visible.
