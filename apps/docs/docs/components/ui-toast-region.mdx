# Toast Region

Live-region container primitive for stackable dismissible toasts.

## Component Reference

<ComponentExamplesApiTabs component="ui-toast-region" />

## Attributes

| Name | Type | Default |
| --- | --- | --- |
| `open` | `boolean` | `true` |

## Properties

| Name | Type |
| --- | --- |
| `open` | `boolean` |

## Events

| Name | Detail |
| --- | --- |
| `open` | `{ open: true, reason, trigger }` |
| `close` | `{ open: false, reason, trigger }` |
| `dismiss` | `{ id, reason, trigger }` (consumer-owned removal request) |

## Slots

Default slot with toast nodes marked using `data-ui-toast`.

Handle `dismiss` by removing the matching toast from application state. The
region observes that list update and emits `close` when the final toast is gone;
it does not remove or apply visibility attributes to framework-owned children.

## SSR Markup

```html
<ui-toast-region>
  <div id="saved-toast" data-ui-toast>
    Profile saved.
    <button type="button" data-ui-toast-dismiss aria-label="Dismiss">Dismiss</button>
  </div>
</ui-toast-region>
```

## Framework Snippets

```vue
<script setup lang="ts">
import { ref } from "vue";
import { ToastRegion } from "@threadlabs/looma/vue";

const toasts = ref([{ id: "saved", message: "Saved." }]);

function dismiss({ id }: { id: string }) {
  toasts.value = toasts.value.filter((toast) => toast.id !== id);
}
</script>

<template>
  <ToastRegion @dismiss="dismiss">
    <div v-for="toast in toasts" :id="toast.id" :key="toast.id" data-ui-toast>
      {{ toast.message }}
      <button type="button" data-ui-toast-dismiss aria-label="Dismiss">Dismiss</button>
    </div>
  </ToastRegion>
</template>
```
