# Wizard

A controlled staged workflow shell with ordered step navigation, current content and an Action Bar. The host supplies stage content, validation, saving, availability and navigation. Completed stages show a check; current and upcoming stages show their number. Mark inaccessible future stages disabled. Optional hrefs preserve native navigation before JavaScript. The navigate event reports the requested value, previous value and trigger without changing value. The default slot contains the current stage; secondary and primary slots compose Action Bar for host-supplied Back, Continue or Finish actions. The disabled prop affects step navigation; the host disables its own content and actions when needed. Shared theme tokens provide palette-aware states and the step list wraps at narrow widths.
