# Status Message

The one way a view says it is loading (`kind="loading"`, with a spinner), has nothing yet (`kind="empty"`, the default), or failed (`kind="error"`, in the danger tone and announced at once), with an optional next step in the `action` slot. `layout="panel"` sets it on a dashed surface for an empty area in a page; `layout="fill"` centres it in all the space, for a whole view.
