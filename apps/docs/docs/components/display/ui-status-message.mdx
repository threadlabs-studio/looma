# Status Message

Shows the loading, empty, or failed state of a content area, with an optional next action. Inline layout uses the surrounding area’s existing boundary; panel adds a boundary, and fill centers a whole-view state. Loading and empty states use a live status region; errors use an alert. Use Callout for static guidance and FormField for errors tied to a specific input.
