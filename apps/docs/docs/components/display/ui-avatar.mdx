# Avatar

Image and fallback initials primitive for identity surfaces such as profiles and assignees.

Initials are drawn in the theme's subtle accent text on its soft accent surface, the same pairing as
a subtle accent Badge, so a theme tunes that one token (`--ui-accent-subtle-text`) to keep both
readable. `--ui-avatar-surface` and `--ui-avatar-text` set an avatar's own colours instead.
