# Text

Running text on the type scale, in a tone that says what it is: default for content, `secondary` for supporting prose, `muted` for metadata and hints, `danger` for an error, `success` to confirm one. `variant="eyebrow"` is a short uppercase label that names a group; `variant="code"` sets a value to read exactly, such as an address. A view never styles text of its own: it picks a size and a tone. A link inside Text is underlined, so it reads as a link by more than its colour.
