# Text

Running text on the type scale, in a tone that says what it is: default for content, `secondary` for supporting prose, `muted` for metadata and hints, `info` for something moving forward normally, `warning` for something that needs attention, `danger` for an error, `success` to confirm one. The words must carry the meaning too, since colour alone does not. `variant="eyebrow"` is a short uppercase label that names a group; `variant="code"` sets a value to read exactly, such as an address. A view never styles text of its own: it picks a size and a tone. A link inside Text is underlined, so it reads as a link by more than its colour.

## Headings

A view's one `h1` is its [Page Header](/components/ui-page-header), and a
[Section](/components/ui-section)'s `heading` is an `h2`. For any other heading, such as a group
inside a section, give Text a heading level with `as`, `h2` to `h6`, and pick its size and weight.
Choose the level for the outline, one below the heading it sits under, not for its look: the
browser's heading size and weight do not apply, so a heading is only as large and as strong as its
`size` and `weight` say.

```vue
<Section heading="Billing">
  <Text as="h3" size="md" weight="semibold">Payment method</Text>
  …
</Section>
```

Use `trim` for a compact heading or label whose visible letters should align with adjacent icons
or a surface's padding. It removes extra font space at the capital and baseline edges without
changing font size or line spacing between wrapped lines. Ordinary prose retains its existing
metrics by default; browsers without `text-box-trim` retain normal font metrics.

```vue
<Cluster align="center" gap="s">
  <Icon name="book-open" />
  <Text as="h3" size="md" weight="semibold" trim>Shared reference</Text>
</Cluster>
```
