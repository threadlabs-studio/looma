# Text

Text roles for body copy, display titles, headings, labels, captions, eyebrows and code. Choose the document element independently from its visual role; shared typography and semantic tones keep text consistent.

## Headings

Choose `as="h1"` through `as="h6"` for the document outline independently from the visual role. `variant="display"` supplies a page title, `variant="heading"` supplies a section title, and label, caption and eyebrow cover common supporting roles. The default body variant preserves existing explicit `size` and `weight` behavior.

[Page Header](/components/ui-page-header) and [Section](/components/ui-section) remain composed title patterns. Choose heading levels for document structure rather than their appearance.

```vue
<Section heading="Billing">
  <Text as="h3" size="md" weight="semibold">Payment method</Text>
  …
</Section>
```

Use `trim` for a compact heading or label whose visible letters should align with adjacent icons
or a surface's padding. It removes extra font space at the capital and baseline edges without
changing font size or line spacing between wrapped lines. Ordinary prose retains its existing
metrics by default; browsers without `text-box-trim` retain normal font metrics.

```vue
<Cluster align="center" gap="s">
  <Icon name="book-open" />
  <Text as="h3" size="md" weight="semibold" trim>Shared reference</Text>
</Cluster>
```
