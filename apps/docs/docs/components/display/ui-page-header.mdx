# Page Header

The top of a view: its one `h1`, with an optional icon or mark before it (`leading`), a short `eyebrow` above it, a `description` under it, and the view's own `actions` at the end. Every view titles itself the same way, at the same size. `align="center"` stacks it centred, for a standalone card such as sign-in.
