# Nav Item

One destination in a side or rail navigation: the sections of a product, or the parts of a record.
Every item has the same shape and marks where you are the same way, so no one hand-builds a
navigation button.

## Parts

- **leading**: something to find it by, usually a `ui-icon`.
- **label** (the default slot): its name.
- **description**: an optional line under the label, such as the record a section belongs to
  ("Pine Street Motors" under "Customer").

The label and the description are one line each and end in an ellipsis, so every item is the same
height and a narrow rail never grows sideways. Everything in the item is its accessible name.

## Link or button

Like Button, the item is one real element, and `as` picks which:

- `as="a"` with `href` is a real link. A modified click, "open in new tab", and the browser's
  history all work, and `target` and `rel` pass to it. Use it for anything with a URL.
- Without it the item is a `button type="button"`, for switching views inside the app with a click
  handler. It never submits a form.

A router drives a link item through the link it renders. In Vue, give Vue Router's `RouterLink` the
`custom` prop and hand its `href` and `navigate` to the item, so a plain click routes in the app
and a modified click still opens a new tab:

```vue
<RouterLink v-slot="{ href, navigate, isActive }" to="/shipments" custom>
  <NavItem as="a" :href="href" :current="isActive ? 'true' : 'false'" @click="navigate">
    <template #leading><Icon name="truck" /></template>
    Shipments
  </NavItem>
</RouterLink>
```

Set `density="compact"` for the smaller type and row spacing used alongside a compact tree.

## Current

`current` marks where you are. It sets `aria-current`, which assistive technology announces:
`current="true"` (or `current="page"`) is the page, `current="step"` the step of a process, and `current="location"`
your place in a set. Set it on one item at a time.

The default `variant="surface"` uses a faint selected surface and accent text, with the same
label weight as an unselected item. It has rounded corners and no edge stripe. Set
`variant="line"` for a square item with a continuous line along its logical start edge. The line
moves to the right in a right-to-left page. These are complete treatments; do not combine a rounded
surface with an inset stripe.

**Migration:** the default used to combine rounded corners, a stronger label, and an inset bar.
Use `variant="line"` when the edge marker is useful. Its default width now follows the global
accent-line width rather than a separate three-pixel value.

Both treatments retain an inset keyboard-focus outline. In forced colors, a current surface item
gets a complete highlight outline; a line item retains its highlight edge. Focus remains distinct
from selection.

| Token | Default | Sets |
| --- | --- | --- |
| `--ui-selection-surface` | 6% accent mixed into the page surface | Selected rows across navigation, trees, lists, search and choices. |
| `--ui-selection-text` | `--ui-accent-subtle-text` | Their selected foreground. Explicitly colored icons keep their colors. |
| `--ui-selection-radius` | `--ui-radius-md` | Their surface corners. Line navigation stays square. |
| `--ui-nav-item-indicator-width` | `--ui-accent-line-width` | The line variant's edge width. |
| `--ui-nav-item-indicator-color` | `--ui-accent` | The line variant's edge color. |
| `--ui-nav-item-current-surface` | `--ui-selection-surface` | A deliberate surface override on this instance. |
| `--ui-nav-item-inline-size` | `100%` | The item's width. It fills its container unless set. |

## Grouping

There is no navigation wrapper component: the semantics are native HTML. Put the items in a `nav`
with an `aria-label`, so the navigation is a landmark, and in a List with an `li` around each item,
so it is announced as a list with a count:

```html
<nav aria-label="Main">
  <ui-list>
    <li><ui-nav-item as="a" href="/shipments" current="true">Shipments</ui-nav-item></li>
    <li><ui-nav-item as="a" href="/invoices">Invoices</ui-nav-item></li>
  </ui-list>
</nav>
```

The List owns the space between items. Tab moves through them, as through any links; arrow keys
are for menus and tabs, not navigation.
