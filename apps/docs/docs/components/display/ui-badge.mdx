# Badge

Lightweight status and label primitive with minimal styling hooks.

`shape="dot"` is a small circular signal using the same tones and variants.
Its text stays available to assistive technology while remaining visually
hidden. Include a short state label, such as “New messages”, or hide a
decorative dot with `aria-hidden="true"` when its parent already names the
state. A dot does not create a live announcement, selection or interactive
control. Use words elsewhere when people need more than a compact signal.

`shape="square"` frames an icon or single glyph in a rounded square. The same
semantic tones and variants apply. Its default size is 32px, or 24px with
`size="xs"`; both follow the global spacing scale. The corners follow
`--ui-radius-md`. Set `--ui-badge-square-size` on a particular badge to change
both dimensions together. It stays non-interactive: use IconButton for an action
and Avatar for a person's identity. Hide a decorative square from assistive
technology when nearby words already name it. Use a pill or tag for longer text.

`shape="circle"` centers one visible glyph or icon in a fixed circle: 24px by default,
or 16px with `size="xs"`, following the spacing scale. Unlike `dot`, its content remains
visible. Set `--ui-badge-circle-size` on the badge to change both dimensions together.
All existing tones and variants apply. Use a pill for longer text, and provide an
accessible name when a single glyph does not explain itself.

Subtle badges and pointed tags have a slightly darker, tone-matched border than their soft fill.
Colored solid badges keep their filled edge; neutral solid uses the same soft treatment as neutral subtle.

Use `variant="outline"` for toned text and a visible edge on the theme surface. It works with
both pill and pointed tag shapes, including right-to-left layouts. On a surface other than the
theme page, set `--ui-badge-surface` on that badge to match its surrounding surface.

Tones mean a status. To colour a category instead, such as Business, Person, and Location, set
`--ui-badge-color` on the badge to any CSS colour. It overrides the tone and derives the rest from
the theme: subtle (the default) gets a 15% wash of the colour and text mixed 35% into the theme's
text colour, which keeps 4.5:1 contrast for any colour in light and dark themes; solid fills with
that text colour and uses the theme surface for its label; outline draws its edge and text in it.
`--ui-badge-surface`, `--ui-badge-text`, and `--ui-badge-border` still win over it.

```html
<ui-badge style="--ui-badge-color: teal">Business</ui-badge>
```


Ordinary SVG-and-text children align and space themselves. Use the `icon` slot for a decorative leading icon that should stay outside the label’s truncation. The icon stays centered and visible when a long label is truncated; keep the state’s words in the default slot.
