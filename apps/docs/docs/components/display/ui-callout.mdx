# Callout

A static semantic message surface with a tone-specific icon. It is not a live alert and does not include dismissal behavior.

The tones are those of VitePress, Docusaurus and GitHub alerts: `note`, `tip`, `info` (the
default), `important`, `warning` and `danger`, with `caution` as an alias of `danger`. `neutral` is
the same muted aside as `note`, and `success` confirms that something worked. `heading` adds an
optional heading above the message. Markdown and LoomaEditor write the same callouts; see
[Shared blocks](/shared-blocks).

The tone shades the background and colors the whole rounded border at an even width.
