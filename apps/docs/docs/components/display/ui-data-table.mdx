# Data Table

A table built from rows of data and its `ui-column` children. Each column is a real header cell, and the table renders a row per item with one cell per column, so it reads as a table before JavaScript and to a screen reader. The header stays in view while the rows scroll; `frozen` on a column and `frozen-rows` on the table keep columns and leading rows in view too. Give the table a bounded height to scroll its rows. For a table written by hand, use [Table](/components/ui-table).

Each [Column](/components/ui-column) shows its `field` of every row, or its own `cell` template, which reads the row as `$row`. `row-key` names the row field that identifies each row, so a row keeps its cells, and the state of any control in them, when the rows change order. `density` sets the row height. While the table scrolls, it is a region the keyboard can focus and scroll, named by its caption.
