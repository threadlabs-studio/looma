# Radio

Radio control primitive for mutually exclusive options, typically composed within `ui-radio-group`.

## Component Reference

<ComponentExamplesApiTabs component="ui-radio" />

## Attributes

| Name | Type | Default |
| --- | --- | --- |
| `checked` | `boolean` | `false` |
| `default-checked` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
| `required` | `boolean` | `false` |
| `value` | `string` | `"on"` |
| `name` | `string` | `""` |

## Slots

Default slot. Often wraps a native `<input type="radio">`.

## SSR Markup

```html
<ui-radio value="starter">
  <input type="radio" name="plan" />
  Starter
</ui-radio>
```
