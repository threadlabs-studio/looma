# Input Group

Fixed text inside a text field, before or after what the user types: `https://` before a site
address, `.example.com` after a subdomain. `ui-input-group` wraps one `ui-input`, draws the Input's
box around both, and shows its `prefix` and `suffix`. The input keeps its own attributes, events, and
form value. See [Input](/components/ui-input#prefix-and-suffix) for how it behaves.
