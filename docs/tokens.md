# Tokens and Theming Contract

The [public theming guide](../apps/docs-next/docs/03.(Foundations)/tokens.md) is the current contract and usage guide.
The source values live in `packages/looma/src/tokens/`; component fallback chains in
`packages/looma/src/components/` define where each group value and component hook applies.


For reading-area and application-chrome roles, see the [public surface guidance](../apps/docs-next/docs/03.(Foundations)/tokens.md#reading-surfaces-and-application-chrome).
