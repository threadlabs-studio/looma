# Material & light

Choose whether surfaces feel flat, raised, matte, polished, or glassy. A shared light source gives their reflection and depth a consistent direction.

## Give each decision a job

::: table

- Recipe key: `outer-depth`
  CSS property: `--ui-outer-depth`
  What changes: How strongly controls and floating surfaces rise above the page.

- Recipe key: `inner-depth`
  CSS property: `--ui-inner-depth`
  What changes: Recession in fields and pressed controls.

- Recipe key: `finish`
  CSS property: `--ui-finish`
  What changes: How strongly a surface catches a reflection, from matte to polished. Reflection also needs nonzero light strength.

- Recipe key: `glassiness`
  CSS property: `--ui-glassiness`
  What changes: Frosting of the scene behind glass, primarily through decorative rims.

- Recipe key: `surface-separation`
  CSS property: `--ui-surface-separation`
  What changes: The material offset around floating content, scaled by the popup's purpose and size.

- Recipe key: `translucency`
  CSS property: `--ui-overlay-translucency`
  What changes: Transmission through decorative rims. At maximum, content plates also reveal a little of the scene.

- Recipe key: `edge-light`
  CSS property: `--ui-edge-light`
  What changes: Light caught at the boundary, independently of depth.

- Recipe key: `glow`
  CSS property: `--ui-glow`
  What changes: Reflected light beyond the surface, from a quiet halo to a stronger bloom.

:::

Depth changes elevation. Finish changes reflection. Transparency changes what shows through. You can change one while retaining the others: turning light strength to zero removes illumination while depth shadows remain.

## Place the light

::: table

- Recipe key: `light-color`
  CSS property: `--ui-light-color`
  What changes: The reflected environment's color, independently of object pigment.

- Recipe keys: `light-x`, `light-y`
  CSS properties: `--ui-light-x`, `--ui-light-y`
  What changes: Position relative to each surface. Coordinates run from 0 to 1; `0.5, 0` is top center.

- Recipe key: `light-spread`
  CSS property: `--ui-light-spread`
  What changes: Concentrated illumination through a broader light source.

- Recipe key: `light-strength`
  CSS property: `--ui-light-strength`
  What changes: Illumination intensity. Components and materials determine how they respond.

:::

In **Customize → Material & light**, drag the light source, use its arrow keys, or enter exact percentages. Shift moves faster; Home returns it to top center. Escape cancels a drag and restores its start.

## Let components choose the treatment

```html
<ui-card variant="elevated">A standard raised card</ui-card>
<ui-card variant="elevated" treatment="expressive">A raised card with the theme's material</ui-card>
<ui-card treatment="expressive">Material treatment on an outlined card</ui-card>
```

`variant` chooses surface structure. `treatment` chooses how much decorative material it expresses. A matte theme stays matte even when a component requests expressive treatment. A card's tone changes its color while preserving its geometry.

The content plane stays nearly opaque so text remains readable. Reduced-transparency and forced-colors preferences suppress ornamental reflection and glow; reduced transparency also disables backdrop blur.
